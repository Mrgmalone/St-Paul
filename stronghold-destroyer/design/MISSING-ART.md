# Missing art for Stronghold Destroyer, most important first

Everything below is drawn in the game today by a stand-in. When you send a picture, it replaces its stand-in.
Pictures from the image generator are cut out by the same tool as the sheet (`tools/cut_units.py`), so please keep
to these rules for every image:

- **Background:** one flat, solid colour filling the whole background, with no shadow, gradient, floor, texture or
  vignette. Use **pure magenta, #FF00FF**: nothing in the game is that colour, so it cuts out cleanly.
- **Style:** the same as the asset sheet: a 2008-era painted RTS look, soft light from the upper left, crisp edges.
- **Colours:** paint units in the sheet's **blue and gold**. The game recolours blue and gold itself (crimson and gold
  for you, Black Stone charcoal and ember for the enemy, and later the four peoples), so one picture serves every team.
- **Camera:** the game looks down from **40 degrees above the ground**. Ask for "three-quarter view from slightly
  above, about 40 degrees" so the pictures sit naturally on the land.
- **One figure per picture**, whole, not cropped, feet at the bottom, standing on nothing.
- **Size:** units **1024 pixels tall** per view (the game shrinks them; bigger cuts out more cleanly);
  machines and buildings **1024 x 1024**; textures **1024 x 1024**.
- **Views:** the sheet has **left, front, right**. Please add **back** (walking away) for every unit. Walking frames
  are optional: if you make them, make **4 frames** of a walk for each view, same size, side by side in one picture.
